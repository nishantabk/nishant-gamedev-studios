# 🎮 Nishant GameDev Studios

> Indie game development studio focused on building immersive 3D games.

## 👋 About

Nishant GameDev Studios is a solo indie studio exploring game development, 3D art, and interactive experiences. The goal is to design, build, and ship polished games.

## 🛠️ Tech Stack

| Area | Tools |
|------|-------|
| Game Engines | Unity 6, Godot |
| 3D Modelling | Blender |
| Programming | C#, GDScript |
| IDE / Editors | Visual Studio |


## ⚙️ Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/[your-username]/[repo-name].git
   ```
2. **Open the project** in Unity Hub (Unity 6) or the Godot editor.
3. **Open the main scene** and press Play.

### Requirements
- Unity 6 (or the Godot version used by the project)
- Windows 10/11
- A GPU capable of running 3D graphics
